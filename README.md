## About

I'm a game security engineer focused on anti-cheat, anti-tamper, and low-level systems.

At Electronic Arts, I'm working on ARM64 support for Javelin, EA's anti-cheat system, porting it to next-generation platforms and extending its protection across new hardware architectures.

Before EA, I worked on Epic Games' game security team, where I contributed to an internal code obfuscator, analyzed commercial cheats, and researched new telemetry and detection methods.

I've also spent several years independently reverse engineering anti-cheat systems and building private tooling for analysis, instrumentation, and emulation. My vulnerability research includes work on Roblox Hyperion through HackerOne.

I'm currently completing a joint Computer Science program through Lakehead University and Georgian College.
